Privacy Policy — Universal GitHub Highlighting
Effective date: October 17, 2026

Universal GitHub Highlighting adds syntax colors to source code on GitHub using a model that runs locally on your device.

Information handled locally
The extension reads source text already available in GitHub repository file views, supported pull request diffs, and Markdown code blocks. This may include private repository code that you can access while signed in. It uses GitHub page and tab URLs to recognize relevant pages, handle navigation, match reload snapshots, and manage the shared GPU runtime. It does not access your browser's history database or collect activity on other websites.

The source is used only to predict syntax colors. It is not executed, used to train a model, or sent to the developer or any external inference service. The model and executable code are bundled with the extension.

Settings and temporary caches
Your enabled/disabled preference and color transition duration are saved in local extension storage until changed or removed by uninstalling the extension.

Recent source text and token positions may be cached in page memory and in a bounded extension browser-session cache to avoid repeated inference. The extension browser-session cache clears when the browser session ends. Individual cache entries may be replaced sooner as other code is processed.

For immediate same-tab reloads, a bounded snapshot containing the page URL, source text, and token positions may be placed in that GitHub tab's sessionStorage. It is eligible for reuse for five seconds and is removed when read by the next document. An unread snapshot can remain until the tab's storage session ends. This page storage is part of the GitHub origin, rather than private extension storage.

The GPU runtime unloads three minutes after the last GitHub tab closes or leaves GitHub, or immediately when highlighting is disabled. Unloading the GPU runtime does not itself clear all cached results. Closing the affected tabs and ending the browser session clears the temporary session caches, subject to the browser's session-restoration behavior.

Sharing and tracking
The extension has no backend, accounts, analytics, advertising, or telemetry. It does not sell, upload, or transfer source text, URLs, or preferences to the developer or third parties. It makes no automatic network requests to external services. Opening a link from the popup or a support link is a user-directed visit governed by the destination site's own practices.

Limited use
Data is handled solely to provide the extension's syntax highlighting feature and its controls. It is not used for advertising, profiling, creditworthiness, or lending decisions. The extension's use of data follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Your choices
You can disable highlighting from the popup or uninstall the extension. Turning it off stops highlighting and closes the GPU runtime; it does not erase your saved settings or necessarily remove temporary cache entries immediately.

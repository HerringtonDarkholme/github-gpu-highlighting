Universal GitHub Highlighting — Chrome Web Store assets

DESCRIPTION
Copy description.txt into the store listing's detailed description field.
short-description.txt contains a concise summary for places that need one.
Suggested category: Developer Tools. Language: English.

PRIVACY
privacy-policy.txt contains the privacy policy.
privacy.html is a standalone page ready for static hosting.
privacy-practices.txt contains the dashboard permission justifications.
After pushing the repository, the policy is publicly available at:
https://github.com/HerringtonDarkholme/github-gpu-highlighting/blob/main/PRIVACY.txt
Enter that URL in Privacy practices, or host privacy.html on your own site.

REGENERATING (from repository root, after npm run build)
CHROME_PATH='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' node scripts/prepare-store-assets.mjs
CHROME_PATH='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' node scripts/render-store-art.mjs
The capture script uses a temporary browser profile and public GitHub pages.
The artwork script renders local HTML/CSS with the existing extension icon.
